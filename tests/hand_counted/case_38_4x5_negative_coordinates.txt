# Both curves use negative integer coordinates, crossing through the
# origin -- just to make sure negative and mixed-sign coordinates are
# handled the same as positive ones (they should be, distances are
# translation-invariant, but worth having a case that isn't all-positive).

algorithm BBMSCore
p 4
-2 -2
-1 -1
0 0
1 1
q 5
-3 -1
-2 0
-1 1
0 2
1 3
expect nca_regular_hops 86
expect nca_shortcut_hops 0
expect shortcuts_written 0
